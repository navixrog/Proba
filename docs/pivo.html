Spoji Firebase
Firebase je Googleov besplatni servis za real-time sinkronizaciju podataka između uređaja. Postavi se za 5 minuta.
1
Idi na console.firebase.google.com i prijavi se Google računom
2
Klikni „Dodaj projekt" → upiši naziv → kreiraj
3
U lijevom izborniku: Build → Realtime Database → Kreiraj bazu → odaberi lokaciju → Test mode
4
Idi na Postavke projekta (⚙️) → Tvoje aplikacije → Web (</>) → kopiraj apiKey i databaseURL
